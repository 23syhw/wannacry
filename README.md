# WannaCry.exe
![Static Badge](https://img.shields.io/badge/Version-2.1-Green)

### An accurate recreation of the infamous WannaCry.exe ransomware, made using VBScript and Powershell.

How to run:

• Go to the [Releases](https://github.com/23syhw/wannacry/releases) page.

• Download the zipped folder, and then unzip it in your files.

• Right click the WannaCry VBScript, click edit in notepad, then copy all the code there exactly how it is.

• Close the notepad, delete the VBScript WannaCry file.

• Make an exact replica by opening notepad, pasting in the code, File<Save As<WannaCry Folder<Wannacry.vbs

• Now do the same with the powershell WannaCry file, except save it as WannaCry.ps1

> [!IMPORTANT]
> This is not for malicious use. Your files will **not** be encrypted, and you can safely close the window and nothing will happen. The script is **purely visual** and will not harm your computer.
